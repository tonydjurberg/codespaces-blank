# Eniro private people scraper

Targets Eniro's public private-person search for Stockholm.

Output:
eniro_private_people.csv

Columns:
first_name, last_name, full_name, address, postcode, city, phone, profile_url, source

Personnummer is intentionally not collected.

Run RUN_ENIRO.bat on Windows. The browser stays visible while scraping and the CSV is saved after each page so the run can resume.

Only publicly displayed Eniro information is targeted. Check Eniro's current terms and applicable data-protection/marketing rules before using the data.
