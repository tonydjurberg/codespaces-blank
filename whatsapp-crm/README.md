# WhatsApp CRM

First sellable front-end MVP for Tony Djurberg Consulting.

## Included
- Inbox/conversations UI
- Contacts
- Sales pipeline
- Calendar placeholder
- Automation templates
- Settings
- Local contact persistence with localStorage
- Responsive layout
- Portuguese/English-friendly UI
- Architecture prepared for Meta WhatsApp Cloud API

## Production integration
Use the official Meta WhatsApp Business Platform Cloud API for real messaging, webhooks, templates and business phone registration. Never put permanent API secrets in browser code.
