# Industritorget Sweden company/contact scraper\n\nScrapes publicly displayed company-directory/profile information from industritorget.se. It stores company-level data and a separate normalized contact table. It does not collect personnummer or hidden/private data.\n\n## First test\n\nThe default run scans 5 directory pages. Change `--pages` to expand the crawl.\n\n```bash\npython industritorget_scraper.py --pages 5\n```\n\nOutputs in `exports/`:\n- `industritorget_companies.csv` — company, address, main phone, mobile phones, website, email(s), profile URL, all detected contact data as JSON.\n- `industritorget_contacts.csv` — one row per publicly displayed contact, including role, mobile, other phones and email.\n- `summary.json` — run counts.\n\nRoles are searched broadly, including VD, Verkställande Direktör, CEO, HR, inköp/inköpsansvarig, ekonomi/CFO, försäljning/sales, marknad, ägare, ledning, administration and other management/contact roles.\n\nThe directory is large, so start with a small page batch, verify the output, then expand.\n
